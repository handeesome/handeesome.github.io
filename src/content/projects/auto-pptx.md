This project is dedicated for weekly church service slide creators in **Chinese Church Bremen Germany**. The best part of the project is the creators only need to focus on the content, without worring about the word fonts and line spacing.

Check out the source code on and try deploy yourself [https://github.com/handeesome/ccg-bremen-auto-pptx](https://github.com/handeesome/ccg-bremen-auto-pptx).

It contains some straight forward forms of names and items that everything is done in one page.

![A simple form](/images/projects/auto-pptx/simple-form.png)

Also, the project of course has the functionality that users don't have to look up **Bible Verses** themselves and insertions are free of work.

![bible verses](/images/projects/auto-pptx/verses.png)

The more advanced tools embeded in this project is the generator of the worship songs. So users can choose between either **downloading** existing pptx files from the church Google Drive, or **creating** the new song pptx themselves using lyrics, completely DIY.

![DIY-lyrics](/images/projects/auto-pptx/DIY-lyrics.png)
